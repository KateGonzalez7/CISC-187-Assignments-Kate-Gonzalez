# Analysis of Sorting Algorithms
### Linear Search
#### In the best-case scenario, the time complexity of the linear search algorithm is $O(1)$. For any average case, the linear search performs an average of $\frac{N}{2}$ work. Since Big-O Notation disregards any constants and multipliers, the time complexity is described as $O(N)$. The worst-case scenario shares this same time complexity with the average-case.
