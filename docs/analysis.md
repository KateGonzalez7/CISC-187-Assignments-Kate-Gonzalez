# Analysis of Sorting Algorithms
### Linear Search
#### In the best-case scenario, the time complexity of the linear search algorithm is $O(1)$. For any average case, the linear search performs an average of $\frac{N}{2}$ work. Since Big-O Notation disregards any constants and multipliers, the time complexity is described as $O(N)$. The worst-case scenario shares this same time complexity with the average-case.
### Hash-table Lookup
#### A search using a hash-table has an amortized time complexity of $O(1)$, in which the time complexity is normally $O(1)$ in average-cases but it is not always guaranteed to be $O(1)$. There are scenarios in which the tracking number's key, determined by the hash function, is calculated to be the same as an existing tracking number's key. Another package with the same key may be found at the beginning of the data structure, to which the search function must now iterate the hashtable to find the actual package. The actual package may not be found until the end of the data structure, which results in a time complexity of $O(N)$.
### Queue Functions
#### Iterations are not required for queue insertion since it is merely appended to the end of the queue. This operation has a constant time complexity, $O(1)$. Removal operations on a queue have a time complexity of $O(1)$, because queues are abstract data types that do not require element shifting, unlike with data structures.
### Implemented Sort Algorithm: Insertion Sort
#### I implemented an insertion sort algorithm on four fields: tracking number, recipient, destination, and weight. To prevent the data structures from being altered by the function, I created copies of the structures and returned the copies. Sorting may help users group packages by destination or another field to process them more efficiently. The average-case time complexity for this algorithm is $O(N^2)$ due to the inspected element being compared to the other elements for each iteration. If each iteration inspects approximately $N$ elements for all $N$ elements, then the work becomes $N * N = N^2$.
